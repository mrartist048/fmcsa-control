How to connect your Google Sheet

Every company uses its own Google Sheet as its database, so your data is never mixed with anyone else's. Setup takes about three minutes and you only do it once.

  1. Create a Google Sheet. Open sheets.new and give it a name, for example "Dispatch - Your Company". Leave it empty.
  2. Open Apps Script. In that sheet click Extensions, then Apps Script.
  3. Paste the code. Press Copy Apps Script code below. In Apps Script select everything in Code.gs, delete it, paste the copied code and click Save (Ctrl+S).
  4. Deploy it as a Web app. Click Deploy, then New deployment, and choose type Web app. Set Execute as to Me and Who has access to Anyone, then press Deploy. When Google asks for permission choose Advanced, then Go to project, then Allow.
  5. Copy the Web app URL. It ends with /exec. Paste it in the box above and press Save & sync.
Changed the code later? Use Deploy, Manage deployments, the pencil icon, Version: New version, Deploy. The link stays the same.

        

      


      
      

        

          
Sales team (CRM logins)

          
Sales agents sign in under CRM Login with the username and password you set here, plus your Company ID . Each agent can be signed in on one device at a time and can keep open only the number of CRM tabs you allow (default 1; change it any time in the Tabs column). Dispatch team logins are created in DMS > Settings.
